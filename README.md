# Sistema-de-Biblioteca
Sistema de Biblioteca aplicando Orientação a Objetos (Herança, Polimorfismo e Encapsulamento). O sistema permite cadastrar livros, alunos e professores, além de gerenciar empréstimos e devoluções.  📌 Tecnologias: Java, Estrutura de Pacotes, ArrayList. 📚 Aprendizados: polimorfismo, regras de negócio, organização em camadas.
